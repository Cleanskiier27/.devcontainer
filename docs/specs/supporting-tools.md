# Supporting tools

This document tracks additional tools that support dev container workflows.

## IntelliJ IDEA

IntelliJ IDEA supports dev containers that can be run remotely via an SSH connection or locally using Docker.

Learn more in the [IntelliJ IDEA documentation](https://www.jetbrains.com/help/idea/connect-to-devcontainer.html).

## Emacs

[GNU Emacs](https://www.gnu.org/software/emacs/) can use dev containers through the community extension [devcontainer.el](https://johannes-mueller.github.io/devcontainer.el/).

The extension is available on [MELPA](https://melpa.org) and from source on [GitHub](https://github.com/johannes-mueller/devcontainer.el).

## CodeSandbox

[CodeSandbox](https://codesandbox.io/) provides cloud development environments and can provision environments from imported GitHub repositories.

## DevPod

[DevPod](https://github.com/loft-sh/devpod) is a client-side tool to create reproducible development environments from a `devcontainer.json` on multiple backends.

## Ona (formerly Gitpod)

[Ona](https://ona.com/) (formerly Gitpod) provides ephemeral development environments for human and agent workflows.

See the [Ona dev container documentation](https://ona.com/docs/ona/configuration/devcontainer/overview) for details.
